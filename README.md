# Diario Pressione

PWA mobile-first per registrare due misurazioni al giorno (mattina e sera) dal 3 al 9 ottobre 2026.

## Funzioni

- Massima, minima e battiti per ogni rilevazione
- 14 slot preimpostati (7 giorni × 2 rilevazioni)
- Modifica dei valori già inseriti
- Medie automatiche
- Dati salvati solo nel `localStorage` del dispositivo
- Invio riepilogo tramite app Mail (`mailto:`)
- Esportazione CSV
- Stampa / salvataggio PDF
- Installabile come PWA e disponibile offline

## GitHub Pages

Pubblicare dalla branch `main`, cartella root (`/`).

> L'app è un diario di registrazione personale e non fornisce diagnosi o interpretazioni cliniche.
